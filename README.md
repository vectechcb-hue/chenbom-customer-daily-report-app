# 承邦客服工作日報 App

這個專案改為「個人手機 App」用途，不再以 GitHub Actions / TestFlight 作為使用入口。

## 使用目標
- iPhone 個人使用
- Android 個人使用
- 日報資料優先儲存在手機本機
- 不要求付費 Apple Developer Program
- GitHub 僅作為程式碼備份與版本管理，不是 App 的使用入口

## 目前功能
- 日期切換
- 上午 / 下午工作項目
- 工作細項自動產生
- 工廠聯繫進度
- 業務工廠回覆
- 本機自動儲存
- iPhone / Android App 架構

## 後續方向
優先把 App 做成「個人直接使用」的手機版本，包含手機友善介面、本機資料保存、匯出功能與語音輸入；不以 TestFlight 或 App Store 作為必要條件。

> GitHub Actions 的 iOS / Android 建置只保留作為技術驗證，不再作為使用者安裝 App 的主要方式。
